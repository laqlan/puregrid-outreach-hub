# Quick Start

1. Login with `pg2180`.
2. Create campaign: `Solar Spain`.
3. Go to Import.
4. Upload CSV. If it fails, open the CSV in Notepad, copy all, and use Paste CSV fallback.
5. Go to Work Queue.
6. Open Gmail, review the email, send.
7. Return to CRM and click Mark Sent.
8. Use Batch to export up to 50 selected messages.
9. Use Settings to download backups.
